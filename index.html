Record ID format
…
How every new record is numbered. Tap a word to add it where the cursor is. Records already saved keep their ID.
Example: …
{CODE} = category + sub category + activity codes · {CAT} {SUB} {ACT} = one of them · {BRANCH} = staff branch · {YYYYMMDD} {YYYY} {YY} {MM} {DD} = date · {SEQ3} = counter with 3 digits (use {SEQ4} for 4). The counter restarts for each different ID start, for example every new day when the date is in the format.
Telegram alert message
…
One line per row. Tap a name to add it where the cursor is. A line is left out when everything in it is empty.
You can use <b>, <i>, <u> and <code>; close them on the same line.
Telegram icons and titles
Tap an icon to choose another one, and rename the title of each line. This changes the standard message lines. Tap Copy on a line and Telegram shows its value in monospace: tapping it in the group copies it. Icons of the added fields are set on each field in the category editor.
